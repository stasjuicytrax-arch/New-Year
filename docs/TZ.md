## 2. Цель, аудитория, тон

### 2.1 Цель
Продать места (столы) на новогоднюю ночь 31.12 в WHITE HALL. Главная метрика — **заявки на бронирование**. Второстепенная — ощущение «это главное событие города», чтобы ссылкой хотелось делиться.

### 2.2 Целевая аудитория
⚠ В исходном брифе указаны «букинг-агентства, промоутеры». По содержанию BIO сайт продаёт столы гостям, поэтому основная аудитория такая:
- **Гости:** пары, компании друзей, семьи с детьми, корпоративные группы из Перми; 25–55 лет; доход выше среднего; хотят «праздник без хлопот» и статусное событие.
- **Вторичная:** партнёры, промоутеры, ивент-агентства. Для них сайт работает как визитка уровня организаторов. Планка качества остаётся «требовательной»: сайт должен выглядеть дороже любого конкурента в городе.
- Основной трафик: **мобильный** (переходы из Instagram, VK, Telegram, рассылок). Mobile-first.

### 2.3 Тон и впечатление
Ультрасовременно, модно, много анимации, **вау-эффект с первого экрана**. Визуальный язык «Хрустальная полночь» (см. DESIGN-SYSTEM §1). Тексты короткие, уверенные, без канцелярита и восклицательных знаков подряд.

## 5. Блоки: подробная спецификация

Тексты брать из `docs/CONTENT.md`. Стили и токены — из `docs/DESIGN-SYSTEM.md`.

### 0. Прелоадер (≤ 2.2 с, только при первом визите в сессии)
Чёрный экран → снежинка-глиф рисуется линией (stroke-dashoffset) → по центру табло `2026` перещёлкивается на `2027` (хром) → цифры разлетаются частицами-снежинками, которые становятся снегом сайта (бесшовный переход в hero). Пока идёт анимация, грузятся hero-ассеты. Если ассеты готовы раньше, можно пропустить кликом.

### 1. HERO — афиша (заменяет прежний вариант с огромным заголовком, 07.10.2026)
Решение клиента: заголовок не должен забивать людей, информация не по углам, декор-ветки и шары убраны. Композиция читается как афиша большого шоу и целиком помещается в один экран (1440×900, 390×844).

**Desktop ≥1024: сплит 40/60.**
- **Справа (60%) ведущие крупно:** вырезка `hosts-cutout` (холст 1024×1536, не кадрирован) шириной `min(60vw, 96svh)`, прижата к правому краю, кадр по бёдра, низ мягко растворяется (маска 46% → 66% высоты холста). За ними два луча и голубое свечение (`.hero__glow`). Имена ведущих мелкой меткой справа внизу. Лёгкий параллакс от курсора (до 12px, только fine pointer) и медленный уход фигуры при скролле.
- **Слева (40%) одна выровненная колонка:** метка `WHITE HALL · 31 ДЕКАБРЯ · ПЕРМЬ` → H1 в 3 строки «ГЛАВНАЯ» (0.62 кегля) / «НОВОГОДНЯЯ» (`--h1 = min(5vw, 11.5svh)`, колонка не шире 40%) / «НОЧЬ 2027» (0.9 кегля, не меньше половины «НОВОГОДНЯЯ») → строка про ТОП-150 → билеты `31 ДЕКАБРЯ` ❄ `СБОР ГОСТЕЙ 21:00` → кнопка «Забронировать стол» → цена и «Количество мест ограничено». Колонка центрируется по вертикали.
- Хром с бликом, который следует за курсором.

**Mobile: вертикально, всё на одном экране:** метка + H1 (кегль `min(13.4vw, 84px)`, «НОВОГОДНЯЯ» целиком, без переноса по слогам) → ведущие крупно (ширина `min(100vw, 500px, 56svh)`, строго по центру, кадр по бёдра, растворение вниз) → строка ТОП-150 → билеты в одну строку → кнопка на всю ширину → цена. Фигура не обрезается краями; без курсорных эффектов.

**Убрано из hero:** ветки ели, ёлочные шары, плашка детской программы (перенесена в главу 06), счётчик (вынесен в узкую полосу `#countdown` сразу под hero), пин-скролл со «влётом камеры».

**Анимация входа (после прелоадера, ≤ 2.5 с):** лучи включаются по очереди → H1 выезжает по буквам из-под маски с бликом → ведущие проявляются из темноты (свет снизу вверх) → билеты собираются из линий → подзаголовок, CTA, имена. Без reduced-motion.

**Fallback:** без WebGL (или `reduced-motion`) снег и боке заменяются статичным слоем WebP, лучи — статичными градиентами.

### 4. «Почему стоит выбрать эту новогоднюю ночь» (плотная)
Не карточки. **Нумерованный список 7 строк во всю ширину**, каждая строка — номер (Cormorant), текст (Onest 500, `--fs-h3`), линия 1px снизу. При наведении по строке пробегает световая полоса, номер становится хромом. При появлении строки выезжают каскадом (`--stagger`). Справа на desktop липкий блок-билет с датой и CTA.

### 5. «Встретьте 2027 год ярко!» (манифест)
Центрированная сцена. Заголовок `--fs-display`. Под ним текст-перечисление, где ключевые слова («шоу, музыка, танцы, иллюзии…») при скролле по очереди подсвечиваются хромом. Фон: «2027» огромными цифрами из частиц-снежинок, собирается при входе в секцию.

### 6. Финальный CTA + форма брони (сцена)
Повтор драматургии hero (лучи, боке), но спокойнее. H2 «Попадите в ТОП-150 гостей…». Слева текст + счётчик (полный формат) + **блок стоимости**, справа форма в рамке-билете.

## 6. Анимация и технологии движения

| Задача | Инструмент |
|---|---|
| Плавный скролл | **Lenis** |
| Таймлайны, scroll-триггеры, pin, SplitText | **GSAP 3** (+ ScrollTrigger, SplitText; все плагины GSAP бесплатны) |
| Снег, боке, частицы, снежный шар, зеркальный шар | **Three.js** (или OGL, если нужен меньший бандл); один общий canvas, `position: fixed` |
| Микро-hover, магнитные кнопки | GSAP `quickTo` |
| Счётчик | собственный модуль, `Intl` + таймзона `Asia/Yekaterinburg` |

Правила:
- Один WebGL-контекст на всю страницу. Пауза рендера, когда вкладка неактивна (`visibilitychange`) и когда canvas вне вьюпорта.
- Частицы: desktop ≤ 1500, mobile ≤ 400; DPR ограничить `min(devicePixelRatio, 1.75)`.
- Только `transform`/`opacity` в анимациях DOM. Никаких анимаций `top/left/width/height`.
- `prefers-reduced-motion` → см. DESIGN-SYSTEM §10.
- Курсорные эффекты только при `(hover: hover) and (pointer: fine)`.
