### 3.3 Фирменные градиенты

```css
:root {
  /* ХРОМ — для display-заголовков и цифр (background-clip: text) */
  --chrome: linear-gradient(180deg,
      #FFFFFF 0%, #EAF0F8 30%, #9AA6C4 48%,

     --chrome (с резкой тёмной полосой на 48–52%) на плоской кнопке читается
     как складка/шов — для кнопок и любых плашек использовать только этот. */
  --chrome-button: linear-gradient(180deg,
      #FFFFFF 0%, #EEF3FA 35%, #D9E2EF 70%, #C3CEE0 100%);

  /* Блик, проезжающий по хрому (анимируется background-position) */
  --chrome-sheen: linear-gradient(105deg,
      transparent 40%, rgba(255,255,255,.95) 50%, transparent 60%);

  /* Луч прожектора */
  --beam: linear-gradient(180deg,
      color-mix(in oklab, var(--cyan-300) 70%, transparent) 0%,
      color-mix(in oklab, var(--electric-500) 35%, transparent) 40%,
      transparent 100%);

  /* Фон-сцена: свет сверху-по-центру + виньетка */
  --scene: radial-gradient(120% 80% at 50% -10%, #12317A 0%, var(--night-900) 45%, var(--night-1000) 100%);
}
```

### 3.4 Пропорции и правила
- **60 / 30 / 7 / 3:** ночь 60% · лёд/серебро (текст, хром) 30% · электрический синий 7% · тёплый янтарь 3%.
- Тёплый янтарь только как свет (боке, огоньки, точка в счётчике). Никогда как фон кнопки или блока.
- Чисто белый `#FFFFFF` только в бликах хрома и снежинках-частицах. Текст — `--frost-100`/`--snow-50`.
- Контраст: основной текст ≥ 7:1, вторичный (`--ice-200` на `--night-950`) ≈ 11:1, проверено. Синий `--electric-500` **не использовать для мелкого текста** на тёмном (контраст < 4.5).
- Фото, кроме фото в «снежном шаре», проходят цветокор под бренд (см. §9).

Ритм страницы: **Сцена → Пауза → Глава → Глава → Пауза → Глава → … → Плотная → Пауза → Сцена**. Никогда две «Плотные» подряд, никогда больше трёх «Глав» подряд без паузы.

- Внутри блока: заголовок → текст `--space-6`; текст → кнопка `--space-7`; label → заголовок `--space-4`.
- Между крупными смысловыми группами внутри секции минимум `--space-9`.
- Пустое пространство — часть роскоши: на desktop у каждой главы минимум 30% площади экрана свободно от контента (там живут свет и частицы).

## 7. Главные приёмы и визуальные ходы

1. **Хромированная типографика с живым бликом.** Заголовки залиты `--chrome`; при появлении по буквам проезжает блик `--chrome-sheen` (1.2s, один раз), на desktop блик следует за курсором (смещение `background-position` по X, лёгкое).
2. **Лучи прожекторов.** 2–4 конуса света (`--beam`, `mix-blend-mode: screen`, blur 40–80px) из верхних углов, медленно качаются (8–14s, ease-in-out, бесконечно). Есть в hero и финальном CTA, на остальных секциях один слабый луч.
3. **Снег-частицы (WebGL).** Сквозной слой на всю страницу, `position: fixed`, 3 глубины (размер/скорость/blur), реагирует на скорость скролла (ускоряется/«ветер») и курсор (лёгкое отталкивание). На mobile — в 3 раза меньше частиц.
4. **Боке гирлянд — едва заметное.** Только мелкие огоньки (диаметр 6–28px, не больше), края полностью размыты (гауссово затухание, без видимого контура круга), непрозрачность 0.04–0.12. Большие синие диски запрещены: на тёмном фоне они читаются как «пятна/кружки» и спорят с текстом. Количество: в hero и финальном CTA до 25 штук, в остальных секциях не больше 8 и только по краям экрана, под текстом — никогда. Тёплых (янтарных) ~30%. Параллакс медленнее контента (0.3×). Главный атмосферный слой — снег, боке лишь подсвечивает его.
5. **Передний план за краями.** Ветки ели, ёлочные шары, кусочки серпантина на переднем плане у краёв экрана, параллакс быстрее контента (1.3–1.6×). Подготовить как PNG/WebP с альфой (сгенерировать или вырезать; см. ТЗ). Ёлочные шары **висят и покачиваются** (pendulum, 4–7s).
6. **Рамка-«билет» (с афиши).** Блоки дат/времени и ключевые карточки — в рамке со **срезанными углами** (chamfer 14px), линия 1px `--line-strong`, внешнее свечение `--accent-glow`. Реализация через `clip-path` + псевдоэлемент или SVG-рамку, растягиваемую по 9-slice.
7. **Снежинка-глиф.** Единый глиф (тонкая 6-лучевая снежинка с афиши, SVG, stroke 1.25px) — разделитель между датой и временем, маркер списков, лоадер. Медленно вращается при наведении.
8. **Диско-шар и световые зайчики.** В сцене DJ/танцев по экрану бегут световые блики (пятна `--frost-100`, blur), как от зеркального шара. Курсор на desktop отражается «зайчиком».
9. **Снежный шар (из референса).** Сфера с бликом и преломлением; внутри — фото/видео (ведущие или будущее видео-превью). На hover/скролл снег внутри шара взмётывается.
10. **Нумерация глав 01–11 (из референса).** Огромная хромированная цифра (`--fs-num`) + label «ГЛАВА 01» + название. Цифра при скролле «перещёлкивается» как табло.
11. **Переход 2026 → 2027.** Сквозной мотив: в прелоадере цифра года перещёлкивается с 2026 на 2027; в футере «2027» собирается из частиц-снежинок.
12. **Обратный отсчёт до полуночи по Перми** (`2027-01-01T00:00:00+05:00`) в стиле табло: дни : часы : минуты : секунды, цифры Cormorant SC + хром, двоеточие мигает тёплым янтарём.

## 8. Компоненты (визуальная спецификация)

### Кнопки

| **Primary «Забронировать стол»** | Заливка `--chrome-button` (мягкое серебро без полосы; `--chrome` с тёмной полосой на кнопках запрещён), тонкая внутренняя подсветка сверху `inset 0 1px 0 rgba(255,255,255,.9)` и внешнее свечение `--accent-glow` 40%, текст `--night-950`, Onest 600 15px uppercase трекинг 0.16em, высота 60px (mobile 56), padding-inline 36px, углы chamfer 10px | hover: блик проезжает по кнопке + свечение `--accent-glow`; магнитный эффект на desktop (смещение до 8px к курсору); active: scale .98; focus: `--focus-ring` |

Под primary-кнопкой мелкая подпись `--fs-label` `--text-muted`: «Количество мест ограничено» (приём из референса 3).

### Рамка-билет (`.ticket`)
Chamfer 14px, линия 1px, фон `--surface` + `backdrop-filter: blur(10px)` **только** если под ней есть движущийся фон. Внутри: label + крупное значение (`--fs-num`). Используется для «31 ДЕКАБРЯ», «СБОР ГОСТЕЙ 21:00», «WHITE HALL», плашки детской программы.

### Глава программы (`.chapter`)
Номер (хром), label «ГЛАВА 0X», заголовок `--fs-h2`, текст 2–3 строки, медиа. Три схемы раскладки:
- **A** — медиа full-bleed на фоне, текст поверх в нижней трети с градиент-подложкой;
- **B** — сплит 5/6 колонок, медиа с маской-аркой или chamfer;
- **C** — без медиа: огромное слово-образ (например «ИЛЛЮЗИЯ») хромом на всю ширину + абзац + анимированный световой эффект вместо фото.

### Поле формы
Высота 56px, фон `--night-900`, нижняя линия 1px `--line`, label плавает вверх при фокусе, фокус-линия `--neon-400` с glow. Ошибка — `#FF8A8A` текстом под полем (единственный «красный» на сайте).

### Иконки
Линейные, stroke 1.25px, `--neon-400`, размер 24/32px, один стиль (Lucide как база + кастомные снежинка/шар/бокал). **Эмодзи из BIO на сайт не переносим.**

### Радиусы и тени
- Радиусы: `0` по умолчанию; `chamfer` вместо скруглений. Скругление `999px` только у плашки детской программы (как на афише) и у снежного шара.
- Теней «на подложке» нет. Глубина — только свечением (`--accent-glow`) и светом.

## 9. Фото и медиа
- **Цветокор под бренд:** все фото (кроме детских) — холодный баланс, тени уводим в `--night-950`, света в `--frost-100`, лёгкий синий split-toning. CSS-вариант: слой `--night-900` с `mix-blend-mode: color` 25–40% + виньетка.
- **Детские фото** (яркие, дневные) — не перекрашиваем в синий целиком, а кладём в «тёплое окно»: рамка-билет, внутри фото с мягким янтарным свечением. Блок детской анимации допускает больше тёплого цвета (до 15%).
- Фото DJ (1254×1254, квадрат) — средний формат до ~900px, не full-bleed; неоновые лучи кадра продолжаются лучами сайта за его границами.
- Форматы: AVIF + WebP + JPEG fallback, `srcset` 640/960/1440/2048, `loading="lazy"` кроме hero.
- Видео (когда появится): MP4 H.264 + WebM, ≤ 6 МБ для фоновых петель, `muted playsinline loop`, постер обязателен.

## 10. Движение (motion tokens)

```css
:root {
  --ease-out:     cubic-bezier(0.16, 1, 0.3, 1);   /* expo-out: появления */
  --ease-in-out:  cubic-bezier(0.83, 0, 0.17, 1);  /* quint: переходы сцен */
  --ease-swing:   cubic-bezier(0.45, 0, 0.55, 1);  /* sine: качание шаров, лучей */
  --dur-1: 180ms;  /* hover, микро */
  --dur-2: 400ms;  /* появления элементов */
  --dur-3: 800ms;  /* заголовки, маски */
  --dur-4: 1200ms; /* блик хрома, сцены */
  --dur-5: 1800ms; /* прелоадер, большие переходы */
  --stagger: 60ms; /* шаг по буквам/словам */
}
```

Правила:
- Появление текста: маска снизу (строка выезжает из-под линии) + лёгкий blur 8px → 0. По словам для заголовков, по строкам для абзацев.
- Всё, что «живёт» постоянно (лучи, снег, шары), — медленно (≥4s цикл), чтобы не утомлять.
- Одна «главная» анимация на экран; остальное — фон.
- `prefers-reduced-motion: reduce` — отключаются параллакс, pin-скролл, частицы (заменяются статичным снегом-PNG), блик хрома показывается статично.

## 11. Анти-шаблоны (запрещено; сверено со списком impeccable «slop» и taste-skill)
- Фиолетово-синий «AI-градиент» без смысла: наш синий — это свет прожекторов, он всегда имеет источник.

- Центрирование всего подряд; одинаковые отступы у всех секций.
- Скругления 16–24px «по умолчанию».
- Бесконечные анимации на мелких элементах UI.
