# CLAUDE.md — «Главная новогодняя ночь 2027»

Одностраничный промо-сайт новогоднего вечера в Перми (WHITE HALL, 31.12, сбор 21:00). Домен: **ngperm.ru**. Цель — заявки на бронирование столов.

## Прочитать перед любой работой
1. `docs/TZ.md` — техническое задание (структура, блоки, анимации, стек, план, приёмка).
2. `docs/DESIGN-SYSTEM.md` — токены, типографика, сетка, ритм, приёмы, анти-шаблоны.
3. `docs/CONTENT.md` — все тексты и факты. Тексты не выдумывать, брать только отсюда.

## Обязательные скиллы
- **Impeccable** (`/impeccable …`): `init` на старте; `typeset`, `layout`, `colorize`, `animate` по ходу; `critique` после каждой секции; `audit` + `polish` перед каждым пушем этапа.
- **Taste Skill**: `design-taste-frontend` (всегда), `high-end-visual-design` (hero и главы), `full-output-enforcement` (всегда, без заглушек).
- Если `/skills` их не показывает, см. TZ §1.1.

## MOBILE QA — обязательно перед КАЖДЫМ пушем (клиент не должен находить мобильные баги сам)
Основной трафик — телефоны. Мобильная версия должна быть идеальной.
1. Скриптом Playwright (`scripts/qa-mobile.mjs`, создать один раз) прогнать собранный сайт (`npm run build && npx vite preview`) на вьюпортах **360×740, 375×812, 375×940, 390×844, 412×915, 430×932** и **768×1024**, с `isMobile: true, hasTouch: true, deviceScaleFactor: 3`, preloader пропущен.
2. Для каждого вьюпорта: полностраничный скриншот + скриншот каждой секции в `qa/` (папка в .gitignore). **Сам открыть и посмотреть каждый скриншот** (Read), а не только цифры.
3. Автопроверки (скрипт падает при нарушении):
   - `scrollWidth > clientWidth` — горизонтальный скролл запрещён;
   - ключевые медиа (ведущие, фото глав) центрированы: |отступ слева − отступ справа| ≤ 4px, люди не обрезаны краем экрана;
   - у каждого `<img>`: `naturalWidth ≥ ширина_в_CSS × 2` (иначе мыло на ретине);
   - текст ≥ 14px (подписи-лейблы ≥ 11px), тач-цели ≥ 44×44px;
   - ничего не перекрывается фиксированной шапкой; текст не залезает под фото/кнопки;
   - нет переносов слов по слогам в заголовках, заголовок hero влезает целиком.
4. На телефоне без мыши: никаких эффектов от курсора, параллакс только от скролла, анимации не сдвигают вёрстку.
5. В отчёте о шаге писать: «Mobile QA: N вьюпортов, 0 ошибок» + что исправлено.

## Git
- Репозиторий: https://github.com/stasjuicytrax-arch/New-Year.git, ветка `main`.
- **Коммит и `git push` после каждого пункта плана (TZ §8)**: клиент следит за процессом.
- Сообщения коммитов: Conventional Commits на английском + скиллы в скобках, например `feat(hero): chrome title reveal [impeccable animate]`.
- Перед пушем всегда `git pull --rebase --autostash` (в репозиторий иногда коммитят с сайта GitHub).

## Сайт по ссылке
- Автодеплой `.github/workflows/deploy.yml`: каждый пуш в `main` → **https://ngperm.ru** (домен подключён 07.10.2026: DNS в REG.RU — 4 A-записи GitHub + CNAME www, custom domain в Settings → Pages). Файл `public/CNAME` не нужен.
- `base` для Vite подставляется в CI автоматически (сейчас `/`). В `vite.config.ts` base не хардкодить; ассеты только через импорт или `import.meta.env.BASE_URL`.

## Жёсткие правила
- Исходники в корне (кириллические папки, `Referens/`, `BIO.docx`, афиша, PNG ведущих) не изменять и не удалять. Оптимизированные копии кладём в `src/assets/`.
- Файл `Техническое задания для Claude.md` устарел (шаблон другого проекта), игнорировать.
- Display-шрифт только прописными, без курсива. Эмодзи на сайте не используем.
- Mobile-first; `prefers-reduced-motion` обязателен.
- Все места с ⚠ в CONTENT.md — плейсхолдеры через `content.ts`, легко заменяемые; в UI не показывать «Lorem» и «TBD».
